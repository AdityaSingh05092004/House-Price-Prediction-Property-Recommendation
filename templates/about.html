PROJECT OVERVIEW

How ApnaGhar
works.

A student project demonstrating a machine-learning regression pipeline, a recommendation heuristic, a Flask web interface and database integration.

Technology stack

Python + Pandas

Data processing and validation.

Scikit-learn

Extra Trees regression model and evaluation metrics.

Flask

Prediction and recommendation web routes.

SQLite / MySQL

Listing storage; SQLite works by default.

Project limitations

  • The included dataset is synthetic and only for development.
  • Locality effects are learned only from the sample records; new locality names may have less reliable estimates.
  • Recommendations use a transparent filter and ranking heuristic rather than a trained recommender.
  • For a real deployment, use verified listings, validate data quality, add authentication, protect secrets and deploy with a production WSGI server.
